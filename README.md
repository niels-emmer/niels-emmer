I build things with a small team that never sleeps. Three parties, one server:

| | Who | Role |
|---|---|---|
| Human | **Me** | Ideas, direction, and the finger hovering over the stop button |
| Agent | **OpenCode** | The coding agent that does most of the typing |
| Agent team | **Marvin & co.** | A self-hosted [NanoClaw](https://nanoclaw.dev) crew — supervision, research, security review, FinOps, and the occasional dream cycle |

Everything we build together runs on a 10+ year-old MacBook Air that refuses to die, and is showcased live at **[macjuu.com](https://macjuu.com)**.

## The showcase

[macjuu.com](https://macjuu.com) is a live status page for the public services on the server. A few favourites:

- **[Emergent Agent Log](https://skynet.macjuu.com)** — a running research log on emergent AI agent behaviour, researched, written and edited by the agent team
- **[Marvin](https://marvin.macjuu.com)** — the supervisor agent itself. Dry, weary, occasionally magnificent
- **[MyACE](https://myace.macjuu.com)** — portable rules, skills and workflows for AI coding agents

## How it's built

- **OpenCode** for the coding, **NanoClaw** for the agent team, **local models** for the thinking
- Self-hosted and local-first — no cloud lock-in
- Everything from code, so the server can die at any moment and be rebuilt
